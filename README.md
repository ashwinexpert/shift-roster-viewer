# 📅 Shift Roster Viewer

View your monthly shift roster instantly. Upload Excel once, see today's shift distribution for A, B, C, GEN, and MID shifts.

## ✨ Features

- 📤 **Upload Excel** - Upload your monthly roster file
- 📍 **Today's View** - See who's working in each shift today
- 👥 **Shift Groups** - A, B, C, GEN, MID shifts with employee names
- 🔍 **Search Employee** - Find any employee's full month roster
- 📊 **Full Month View** - Complete roster table with color coding
- 💾 **Export Data** - Download backup as JSON
- 📥 **Import Data** - Restore from backup
- 📱 **Mobile Friendly** - Works perfectly on phone

## 🚀 How to Use

1. Open the app
2. Click "Upload Excel" and select your roster file
3. View today's shifts instantly
4. Search any employee to see their full month

## 🛡️ Data Privacy

All data stays in your browser's local storage. No data is sent to any server.
